# example

Starter template — copy this directory to create a new skill. Replace every section below with your own content.

## Requirements

- `curl` (standard on most systems)
- `EXAMPLE_API_KEY` env var (get one at https://example.com/api)

## Usage

### Claude Code

```
Use the example skill to fetch data for X
```

### Direct CLI

```bash
EXAMPLE_API_KEY=your-key bash skills/example/example.sh "hello world"
```
